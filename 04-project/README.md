# 临床数据预测模型实战

从数据到模型报告的完整流程。**重点不是刷 AUC，是走完规范流程。**

## 里程碑

### M0　环境
- [ ] Jupyter 跑通
- [ ] 数据集就位（先不要用自己课题的真实数据）

### M1　理解与清洗
- [ ] pandas 读入数据
- [ ] 处理缺失值、类别编码
- [ ] 产出 **Table 1**（基线特征表，临床风格）

### M2　基线模型
- [ ] 逻辑回归 + **严格 train / validation / test 三分**
- [ ] 只用 train 拟合，用 **validation 选超参数**
- [ ] 测试集**先不要碰**

### M3　诊断
- [ ] 画**学习曲线** → 判断高偏差还是高方差
- [ ] 决定：加数据？加特征？调 λ？
- [ ] 做**误差分析**：打印模型判断错误的样本，看有没有规律

### M4　报告
- [ ] **测试集只跑一次**
- [ ] ROC / AUC
- [ ] **校准曲线**（calibration curve）
- [ ] **决策曲线分析 DCA**
- [ ] 一页纸的模型报告

### M5　加分项
- [ ] 外部验证
- [ ] 与临床评分对比（如 GRACE、CURB-65、TIMI）

## 数据来源建议

| 难度 | 数据集 | 样本量 |

## ⚠️ 数据安全

**永远不要把患者数据提交到 GitHub。** `data/` 已在 `.gitignore` 中排除。
真实课题数据请本地保存，仓库里只放代码和脱敏后的结果。
